## 项目信息

- **项目名称**：Open PR Reviewer
- **仓库地址**：`https://github.com/<你的用户名>/open-pr-reviewer`
- **一句话定位**：开源免费的 AI 代码评审工具，跑在 GitHub Actions 上，用 OpenAI 自动评审每个 Pull Request。

## 表单问题与参考回答

### 1. 你的角色（What is your role?）

> **参考**：我是 Open PR Reviewer 的创建者和主要维护者。我负责项目设计、核心代码、文档和发布流程，处理 issue 和 pull request 的评审。

### 2. 项目为什么有资格（Why is your project eligible / important?）

> **参考**：Open PR Reviewer 是一个 MIT 协议的开源项目，解决开发者对免费、自托管 AI 代码评审的明确需求。它完全跑在自己的 GitHub Actions 里，代码不进第三方服务器，这对开源项目和无预算的个人开发者尤其重要。仓库提供完整的 CLI、GitHub Action、文档和测试，任何人可以免费使用。

### 3. 你打算怎么用 API 额度（How do you plan to use the API credits?）

> **参考**：我计划用 API 额度做三件事：
> 1. 在真实的开源项目上持续运行 Open PR Reviewer，收集反馈并改进评审质量；
> 2. 用 Codex 处理项目的日常维护——评审 incoming PR、自动修复 issue、跑测试和发布；
> 3. 把这个项目推广给更多开源仓库使用，验证它在大规模 PR 工作流下的效果。
